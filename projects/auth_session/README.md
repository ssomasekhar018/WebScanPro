# Authentication and Session Security Analysis Project

This project simulates and analyzes authentication and session security events to identify potential threats and anomalies. It includes scripts for generating a dataset of login events, extracting features, and preparing the data for machine learning analysis.

## Project Structure

```
projects/auth_session/
├── data/
│   ├── attack_patterns.csv
│   ├── login_session_dataset.csv
│   └── feature_dataset.csv
├── docs/
│   ├── auth_patterns.md
│   └── dataset_notes.md
├── logs/
│   ├── raw_login_events_<timestamp>.log
│   └── scan_run_<timestamp>.log
├── ml/
│   ├── feature_extractor.py
│   └── model_prep_utils.py
├── scanner/
│   ├── auth_scanner.py
│   ├── config.py
│   └── core.py
├── docs/
│   ├── auth_patterns.md
│   ├── dataset_notes.md
│   ├── fail_count_60m_distribution.png
│   └── fail_count_vs_distinct_ips.png
└── tests/
    └── test_auth_scanner.py
```

## Files and Directories

*   **`data/`**: Contains all data files, including the attack patterns, the raw and processed datasets, and the final feature dataset.
*   **`docs/`**: Contains documentation files, including the authentication patterns and notes on the dataset.
*   **`logs/`**: Contains log files generated by the `auth_scanner.py` script.
*   **`ml/`**: Contains scripts related to machine learning, including feature extraction and model preparation.
*   **`scanner/`**: Contains the scripts for simulating and scanning authentication events.
*   **`tests/`**: Contains tests for the project.

## How to Run

1.  **Start the mock server**:

    ```bash
    python projects/auth_session/mock_server.py
    ```

2.  **Run the authentication scanner**:

    ```bash
    python projects/auth_session/scanner/auth_scanner.py
    ```

3.  **Run the feature extractor**:

    ```bash
    python projects/auth_session/ml/feature_extractor.py
    ```

## Final Deliverables

*   **`login_session_dataset.csv`**: A dataset of simulated login and session events.
*   **`feature_dataset.csv`**: A dataset of features extracted from the login and session events, ready for machine learning analysis.
*   **`auth_patterns.md`**: A document defining the authentication and attack patterns used to generate the dataset.
*   **`dataset_notes.md`**: A document with notes on the dataset, including data sanitization rules and labeling heuristics.
